# 版本迭代记录

记录 Kiwi 的功能演进与重要修复。版本号遵循语义化版本：主版本表示架构或数据模型的不兼容变更，次版本表示向下兼容的新功能，修订版本表示向后兼容的问题修复。

## 未发布

### 新增

- 新增桌面版前端构建（`npm run build:desktop`）：改用系统字体栈并移除 Google Fonts 与 emoji CDN 回退；远程图片、图册、YouTube 与网页嵌入显示本地占位，编辑器与阅读态均不发起外网请求。Docker / Web 构建行为保持不变。
- 新增桌面设置页（`/settings/desktop`）：展示本地运行状态与数据 / 日志目录，集中管理「允许连接外部模型接口」与「本机代码执行」开关，两者默认关闭且开启前必须确认风险。
- 未配置模型时，问答、Wiki 编译、学习出题与向量设置显示明确的「未配置模型」空态和设置入口，不再自动请求外部接口。
- 新增 Windows 桌面版安装包构建链路：`desktop/build.ps1` 一键构建桌面前端、PyInstaller runtime、便携 Python 与 .NET WebView2 宿主，并生成 Inno Setup 安装包与 SHA-256；第三方组件版本与校验值固定在 `desktop/versions.json`。
- 新增 Windows 发布工作流：推送 `v*` 标签或手动触发时构建安装包，执行静默安装、安装后 smoke-test、卸载与用户数据保留检查，并可选择证书签名。
- 新增 `docs/WINDOWS.md`：安装、离线边界、模型配置、本机代码执行、备份恢复、故障排查与源码构建说明。
- 导入 PDF 并勾选「强制 OCR」时，自动裁剪页面内嵌图片与 DeepSeek-OCR grounding 图块，保存到知识库媒体目录并以 Markdown 图片链接插入笔记对应页；大模型排版阶段会保留或补回被遗漏的图片链接。
- 上传进度改为顶部居中常驻卡片：编辑器附件、数据表附件字段、语音转写音频与知识库导出包导入均显示百分比和进度条；尚未收到进度事件时显示脉冲进度与「正在读取文件并建立连接」，GB 级文件不再看起来「没有反应」。进度卡片提供「取消」按钮，可中止正在上传的文件；点击卡片不再误关闭提示。
- 问答支持 Agent 能力：可 @ 指定笔记或目录（目录自动包含子目录）限定本轮检索范围，Agent 模式自动拆分并列问题多路检索，联网开关在知识库之外补充网页结果并以「网页」引用展示。
- 问答回答下方的引用只展示正文实际引用到的来源，不再固定列出检索命中的全部 10 条；历史会话加载时同样按正文引用重新编号。
- 笔记页内查找（Ctrl/⌘+F）支持替换：展开替换行后可替换当前一处或全部命中，替换词留空即删除；改动进入撤销历史并触发自动保存，只读视图会提示切换编辑视图。

### 变更

- 项目由专有许可切换为 GNU AGPL-3.0，以匹配安装包内置的 PyMuPDF；Windows 安装包同步包含 `LICENSE`，README 与 `THIRD-PARTY-NOTICES.md` 说明源码获取与再分发义务。
- `deploy.sh` 改为渐进式交互向导：按需询问访问地址、访问令牌、端口冲突、前端构建、部署前备份与 Cloudflare 隧道；`--yes` 保留非交互部署。
- 生产 Compose 新增可选 `cloudflared` 服务（`cloudflare` profile），可用 `./deploy.sh cloudflare` 一键配置、启动和停止公网只读分享。
- `./deploy.sh cloudflare` 支持用 Cloudflare API Token 自动创建隧道、写入路径白名单 ingress 并添加 DNS 解析，只需填写分享域名；同时支持用户级 Token（`cfut_`）与账户级 Token（`cfat_`，需 Account ID）。配置前会校验域名格式、所属区域与解析冲突，API Token 不写入 `.env.prod`。
- `./deploy.sh update` 改为重建 backend 容器，使 `.env.prod` 中的环境变量变更立即生效。
- 运维页的后台任务与审计日志改为服务端分页；已结束的任务与审计记录默认只保留近 14 天，可通过 `KIWI_OPS_RETENTION_DAYS` 调整或关闭。
- 置顶组件插件浮窗按内容自动调整高度，打开时不再出现内部滚动条；手动缩放后仍可保持自定义高度。
- 贴一贴卡片打开主窗口时连续展开为工作区，页面内容随展开直接呈现。
- 内置知识库页面统一为全宽阅读布局。
- 内置知识库的交叉引用改为 @ 提及，说明文字同步更新，不再出现 `[[...]]` 旧写法；Wiki 正文可直接渲染并跳转 @ 提及链接。
- 编辑 / 学习模式切换时沿用当前知识库，不再跳回各模式上次选择的库。
- 笔记表格支持拖动列边框调整列宽、拖动行底边调整行高；列宽与行高随表格写入正文，刷新后保留。
- 问答会话按知识库隔离：列表只显示当前知识库（以及全局范围）的会话，切换知识库自动刷新，清空历史也只影响当前知识库。
- 删除数据表记录不再连带删除对应笔记：删行时行笔记降级为普通文档保留在原目录；行笔记移入回收站只解除绑定，恢复时自动重新绑定。

### 修复

- 修复浏览器无权读取所选文件时上传一直停在 0%、既不报错也无法取消的问题（典型场景：Snap / Flatpak 版 Firefox 读取不属于当前用户的下载文件，或文件位于已断开的移动硬盘 / 网盘）。上传前先读取 1 字节校验可读性，失败立即说明原因并提示把文件复制到主目录后重试。
- 修复编辑器「插入附件」未携带 `any_type`，导致视频 / 音频 / 压缩包等大文件完整上传后才被 415 拒绝的问题；附件入口现与后端「不限类型」语义一致。
- 修复导入对话框选择超过 200MB 的文件时只在列表底部留下静态提示、看起来毫无反应的问题：超限文件立即弹出明确说明，并提示改用「插入附件」上传大文件。
- 修复备份任务因后端镜像内的 `pg_dump` 15 与 PostgreSQL 16 服务端版本不匹配而失败；镜像改用 PGDG 源安装 `postgresql-client-16`，并支持通过 `PGDG_MIRROR` 切换镜像站。
- 备份优先使用配置的 `pg_dump` 路径（桌面版指向随包的 PostgreSQL 16），并在桌面版一并备份 `fernet.key`，换机恢复后已保存的模型密钥仍可解密。
- 修复高分辨率界面缩放下编辑器气泡菜单与日期选择弹层定位偏移、遮挡正文的问题。
- 修复语音转写录音在 HTTP 局域网地址下被浏览器安全策略拦截时提示笼统的问题：明确安全上下文限制，并提供「改为上传音频」入口。
- 修复历史版本实际最多保留 100 个、与界面标注的 60 个不一致；现统一为每篇最多 60 个，并在新快照写入时清理超量记录。
- 移除附件 20MB 上传限制：后端流式落盘，前端与 Nginx 同步放开；其他导入接口仍保留原上限。
- 修复线上 OCR 因长提示词输出成片 `}}}}` 的问题：改用简短指令并清洗模型输出，新增「OCR 识别 → 结果解析 → 大模型 Markdown 排版」流程，保留原文语言；同时修正 LLM 接口地址重复拼接 `/v1`。
- 修复开发实例与线上共用数据库时，旧导入记录里的相对原文件路径在容器内失效、重导入报「解析失败：no such file」的问题：上传目录改为绝对路径，读取时按当前上传目录解析旧相对路径，重复导入会用本次上传的文件重新落盘并修正记录。
- 修复扫描版 PDF 的 OCR 因单页超时/失败而整份回退到原生文本层的问题：逐页容错、对超时与 5xx 自动重试，失败页回退该页原生文本层，仍无内容时插入占位或整页图；超过单次 200 页上限的部分保留原生文本或页码占位，避免页面静默丢失；同时降低 OCR 页面渲染 DPI 以减少单页耗时。
- 修复 OCR 页眉页脚清理漏判：先掩掉页眉 / 页脚中逐页变化的页码（「第 N 页」「Page N of M」「3/10」）再比较重复行，扩大首尾检测区，两页短文档也会移除页码与含网址 / 联系方式的重复页脚，并避免清理规则把整页内容删空。
- 大附件上传在 Nginx 关闭请求体缓冲并放宽请求 / 转发超时，GB 级文件边收边转发，不再长时间无响应。
- 修复平板打开超长正文笔记卡顿：超过 12 万字符的只读文档改用轻量阅读渲染，编辑器大纲与格式采集防抖，图片懒加载。
- 修复首次登录输入访问密钥后知识库仍为空、需要手动刷新才加载数据的问题：登录成功会先卸载登录组件，其 `success` 事件不再送达；改由访问状态变化触发数据加载，并在拿到知识库列表前显示「正在加载知识库…」。
- 修复只读分享中非图片附件（Office 文档、压缩包等）无法下载的问题：所有附件均强制以下载方式返回，HTML 等活动内容不再内联渲染。

## 1.0.0 — 2026-10-24

首个正式版本：笔记工作区、混合检索与 AI 问答、学习模式、插件扩展和只读分享均已落地。

### 新增

- 笔记工作区：目录树 + 多文档编辑，支持文档、数据表（表格 / 看板 / 画册 / 日历）、表格、画布、Notebook、链接与导入笔记，以及 OCR、链接抓取、附件、语音转写和模板。
- 检索与 AI：混合检索（向量 + BM25 + 可选重排）、按笔记类型 / 标签 / 时间筛选、段落级引用锚点与命中高亮。
- 学习模式：FSRS-5 复习调度、Anki 牌组导入导出、学习周报与 Web Push 提醒。
- 插件与扩展：组件插件 zip 导入、真实预览、启用 / 导出与全局置顶浮窗；内置扩展组件可统一管理和导出。
- 分享与导出：笔记只读分享链接（有效期 / 密码 / 撤销），覆盖全部笔记类型；支持 PDF、DOCX、Anki 与画布导出。
- 效率与体验：全局命令面板（`Ctrl / ⌘ + K`）、笔记内查找（`Ctrl / ⌘ + F`）、贴一贴浮窗、目录树增量刷新、窄屏适配与主题化界面。

### 变更

- 版本号统一升级到 `1.0.0`（前端、后端、Compose 镜像标签），作为首个正式版本发布。
- Wiki 编译只以笔记为输入；编译资格、任务状态与失败重试统一到持久化任务队列。
- 「插件与区块」按内置扩展组件 / 组件插件分区，系统主题色改为全站变量驱动。
- 内置演示知识库与门户页同步到当前版本。

### 修复

- 修复编译任务长期排队或反复失败、表格与画布等笔记无法编译、插件区块布局与预览错位等问题。
- 修复只读分享页滚动、PDF 阅读、目录树双击浮窗、右键菜单重复与代码沙箱启动失败等交互问题。
- 修复笔记搜索命中关联 Wiki 页面报错、切换知识库误报笔记不存在等问题。

## 0.2.0 — 2026-10-21

对应路线图 M1「工程地基」与 M2「稳定性与数据安全」。

### 新增

- 表格笔记（sheet）：新增 `sheet` 笔记类型，支持多工作表、单元格公式与自动保存；原「导入」弹窗可将 Excel / CSV 直接解析为可编辑工作簿，保留工作表名、公式、合并单元格与单元格底色。
- 文本笔记表格增强：表格上下文菜单提供插入 / 删除行列、合并 / 拆分单元格、切换首行 / 首列表头、单元格底色与对齐；新增或删除行列、表头与底色等操作不再出现在主工具栏。
- 自定义文字颜色：工具栏与选区气泡菜单均可取色，支持一键清除；颜色随 Markdown 以 HTML `span` 持久化，编辑、阅读与刷新后保持一致。
- 统一自绘取色器：文本编辑器、选区气泡、表格工具栏与品牌设置共用同一组件，支持预设色板、HSV 面板取色与 Hex 输入，不再弹出浏览器原生取色窗口。
- 表格笔记 Excel 化：列头提供排序与筛选菜单，底部展示筛选条数与一键清除；全选后拖动行高 / 列宽可批量生效，所有列都显示筛选入口。
- 学习模式品牌信息：支持独立 Logo 与一句话描述，未上传 Logo 时沿用品牌 Logo；学习模式默认主题色内置为「翠绿」预设，当前配色在预设或自定义入口上回显选中态。
- 知识库卡片：再次点击当前已选卡片直接进入笔记工作区。
- 编辑模式下的 Wiki 概览不再展示学习状态卡片，仅在进入学习模式后显示。
- 编辑模式统一为「标准编辑」（语雀式）：工具栏、斜杠命令、块拖动手柄与气泡菜单在同一模式下可用，保留「DOCX」排版模式；历史 simple / notion 设置仍可读取。
- 阅读模式工具栏新增目录开关：无需切换到编辑态即可展开 / 收起文档大纲。
- 持久化后台任务：新增 `jobs` 表与单 worker，导入、笔记编译、知识库导入与自动备份改为可恢复任务；支持幂等键、重试退避、取消、失败重试与进程重启后续跑。原「编译任务」页继续展示摄入进度，新增 `GET /api/jobs` 等接口。
- 可观测性：结构化日志附带 request id；健康详情展示 PostgreSQL / Qdrant / LLM 连通性与最近失败任务；`/metrics` 暴露任务队列长度、任务耗时、LLM 延迟与失败率等 Prometheus 指标。
- 前后端构建一致性：Vite 产出 `dist/build-info.json`，后端提供版本 / 提交号 / 启动时间；设置页新增「运维」页，前后端提交不一致时给出醒目提示。
- 自动备份：后端按间隔执行 `pg_dump --format=custom`、归档 uploads 并写入带 SHA-256 的 manifest，按保留天数清理；新增 `scripts/backup.sh` 与 `scripts/restore_backup.sh`，支持宿主机 / Docker 两种模式及恢复前校验。
- 可选访问控制：设置 `KIWI_ACCESS_TOKEN` 后，`/api/*`、`/media/*` 与 `/metrics` 需要令牌；浏览器通过令牌登录页换取 HttpOnly Cookie，媒体 URL 支持 `?token=`；LLM、导入与代码执行接口支持按分钟限流。
- 操作审计：删除、清空回收站、跨库迁移、知识库导出与重建等危险操作写入审计日志，运维页可筛选查看并导出 CSV。
- 上锁笔记加密存储：设置密码锁时可选择以密码派生密钥（PBKDF2 + Fernet）加密正文，数据库中不再保留明文；解锁令牌仅在当前会话内有效，移除密码锁时解密恢复。
- 前端冒烟测试：新增 Playwright 用例，覆盖目录树拖拽（含根目录投放区）、文档编辑 / 自动保存 / 阅读切换、模板创建、密码锁加密与解锁、只读导入、导入解析进度、运维页与访问令牌登录。
- CI 新增 Playwright 任务：使用真实 PostgreSQL / Qdrant 启动前后端，执行全部冒烟用例。

### 变更

- 颜色选择器、扩展组件菜单与表格筛选菜单统一为毛玻璃浮层和图标磁贴样式，新增组件沿用同一套视觉语言。
- 笔记密码锁的「修改密码」在加密笔记上要求先解锁；加密会清除该笔记已有历史版本，界面提供不可恢复提示。
- 删除笔记、清空回收站、跨库迁移等操作在响应前写入审计记录，失败时不落库。
- 知识库导出包升级为包含 manifest、Markdown、附件与学习记录的 `.kiwi.zip`；导入沿用整库导入接口。
- 笔记路由从单个 `notes.py` 拆分为 11 个按领域划分的子路由，`notes.py` 仅保留聚合与注册顺序；共享辅助函数集中到 `notes_shared.py`，移除函数内延迟导入，路由数量与行为保持不变。
- 版本号统一升级到 `0.2.0`（前端、后端、Compose 镜像标签）。

### 修复

- 引用块 / 分栏中的图片在保存时丢失行首 `>` 前缀，重新打开后整段 Markdown 变成乱码；图片围栏改为逐行序列化，宽度调整与再次编辑后仍能正确往返。
- 空待办 `- [ ]` 不再被解析成普通列表文本（此前会保存为 `\[ \]`），编辑与阅读视图均可保留空复选框，含二级空待办的多级清单也能正常往返。
- 待办进度组件改为递归统计全部层级的待办项，二级 / 三级清单不再漏计。
- 空知识库的 Wiki 图谱不再一直停留在「布局计算中」，无节点时直接展示空态。
- 工具栏对齐 / 箭头 / 时钟等图标缺失导致按钮显示为空白，补齐图标定义。
- 语雀 / Notion 粘贴或自定义模板里的原始 HTML 表格（含 `colspan` / `rowspan`）在编辑、阅读与分屏预览中正常渲染；复杂表格保存时回退为 HTML，不再写成 `[table]` 或转义成源码文本。阅读预览的 HTML 统一经 DOMPurify 清洗。
- `:frame_with_picture:` 等 emoji 短代码按表情字符显示；修复短代码别名（主名不同）在保存时被写成字面量的问题。
- PDF 阅读器支持加密 PDF 输入密码解锁；超过 30 秒无下载进度时显示超时原因，并提供重试、浏览器内置阅读器与新标签页打开入口，不再无限转圈。
- 备份脚本与恢复脚本的 uploads 归档路径不一致，恢复后附件会落到同级目录；统一为归档内容根部写入、按目标上传目录解压，并在恢复演练中校验附件字节一致。
- PostgreSQL 18 客户端 `pg_dump` 产物在 PostgreSQL 16 服务端恢复时报 `transaction_timeout` 未知参数；部署文档明确要求使用与服务端同大版本的客户端，并记录使用 PG16 客户端的完整演练结果。

- 内置知识库删除改为真正的级联删除（素材、Wiki、笔记、学习记录与向量索引一并清理），不再只是标记隐藏；删除后知识库页提供「创建内置知识库」入口，按当前随包内容重新生成，旧版软删除记录也会在重新创建时彻底清理。

- 后端容器入口在启动 API 前自动执行 `alembic upgrade head`，升级无需手工迁移。

- 前后端镜像默认使用国内依赖源：后端使用清华 PyPI / Debian 镜像并改为从 PyPI 安装固定版本 `uv`，前端使用 `registry.npmmirror.com`；apt、uv 与 npm 下载均启用 BuildKit 缓存，国内网络下重复构建显著加快。

### 修复

- 线上向量模型保存失败时不再显示 `[object Object]`：前端会把 FastAPI 校验错误转换为可读文案；超时、批大小与并发数在失焦时自动收敛到允许范围，并显示取值范围提示；高级参数区会说明批大小与并发数的含义，以及调高后更容易触发服务商单请求上限或 429 限流的风险。

## 0.1.0 — 2026-10-18

首个完整版本：从笔记工作区、Wiki 编译到学习闭环的全部核心流程可用。

### 笔记工作区

- 统一笔记模型：文档、数据表、导入、外链、画布与 Notebook 共用目录树、标签、模板与双向链接。
- 目录树支持分组、拖拽移动与排序、内联重命名、搜索与展开状态持久化。
- 富文本编辑器：标题、列表、任务列表、表格、代码块、引用、图片、附件、高亮、对齐与斜杠命令。
- 数据表支持表格、看板、画册、日历四种视图，以及字段管理与行内联编辑。
- 文件导入自动解析为可编辑文档，保留原始素材并显示导入进度与解析质量。
- 外链笔记由服务端抓取正文，抓取失败时降级为书签卡片。
- 画布支持绘制工程图与思维导图，箭头智能粘连、节点对齐辅助与主题切换。
- Notebook 在隔离沙箱中执行代码，结果以图形化方式呈现。
- 附件上传与 `/media` 静态访问，图片可直接粘贴或拖入正文。

### Wiki 编译

- 知识库内全部笔记与素材统一进入编译流水线，而非仅导入素材。
- Schema 驱动的概念抽取与页面组织，支持增量编译、引用来源与受影响页面追踪。
- 编译任务展示实时进度、阶段耗时与解析质量，失败项可定位重试。
- 支持整库重新编译；Wiki 页面提供目录、大纲、反向链接与来源逆向跳转。

### 知识星图

- 星图式浏览 Wiki 页面关系，节点大小反映被引次数。
- 支持按页面、笔记等节点类型筛选，悬浮高亮与关系层级控制。

### 学习闭环

- 学习者画像与按掌握度动态排程的学习计划。
- 渐进练习、间隔重复与错题本。
- 仿真考试支持分卷作答、知识点雷达与成绩报告。
- 掌握度回写到 Wiki 页面与学习图谱，薄弱点可直接定位到知识内容。

### 知识问答

- Wiki 与原文混合检索，回答附带可溯源引用，并可回写为新 Wiki 页面。
- 兼容任意 OpenAI 协议模型，API Key 使用 Fernet 加密存储。

### 内置演示

- 首次启动注入「Kiwi 上手指南 · 功能演示知识库」，覆盖全部笔记类型、Wiki 页面、学习计划与考试数据，可修改、删除或还原。
