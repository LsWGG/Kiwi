# 版本迭代记录

记录 Kiwi 的功能演进与重要修复。版本号遵循语义化版本：主版本表示架构或数据模型的不兼容变更，次版本表示向下兼容的新功能，修订版本表示向后兼容的问题修复。

## 0.1.3 — 2026-10-19

### 新增

- 知识问答改为检索 Wiki 与笔记：原文作为导入素材不再直接参与回答，笔记是内容的最终态；回答附带的引用会标注「Wiki / 文档 / 数据表 / 画布 / Notebook」等来源类型，并支持行内 `[n]` 引用点击定位。
- 会话历史持久化：侧栏支持新建、搜索、重命名、删除与清空，刷新页面或切换视图后可继续之前的对话；每条会话保存检索范围、意图侧重与模型覆盖。
- 问答页面 UI 重构：会话标题与轮数、自动保存状态、来源卡片预览与展开、回答复制、自动滚动与「回到最新」、输入框随内容自动增高。

### 变更

- 前端不再在 Docker 镜像构建阶段执行 npm / Vite：生产 Compose 改用 `nginx:1.27-alpine` 运行时镜像，只读挂载宿主机预构建的 `frontend/dist`；前端更新后重新 `npm run build` 即可生效，无需重建或重启容器。
- 后端源码（`app` / `alembic` / `alembic.ini`）以只读 bind mount 挂载进容器：日常代码更新执行 `./deploy.sh update` 重启 backend 即可生效，只有 `pyproject.toml` / `uv.lock` / Dockerfile 变化时才需要重新构建镜像。
- `./deploy.sh frontend` 可在宿主机单独重建静态产物；`frontend/dist` 缺失时 `./deploy.sh` 会自动构建一次。
- `deploy/frontend.Dockerfile` 调整为可选的运行时镜像，仅 `COPY` 预构建的 `dist`，供需要不可变镜像的部署使用。

### 修复

- 修复低内存主机在 `docker build` 阶段执行前端打包时被 OOM 杀死（退出码 137）的问题。
- 问答检索增加最低相似度阈值（`KIWI_RETRIEVAL_MIN_SCORE`，默认 `0.4`）：闲聊或与知识库无关的问题不再把低分内容当作资料，回答「知识库中未找到相关内容」时不会附带无关引用来源。
- 修复全新环境部署后没有内置演示知识库的问题：演示数据中的纯日期字段（学习画像的目标日期）此前未转换为 `date`，导致首次建库事务回滚；新环境启动时会正常写入全部演示内容。
- 内置知识库删除改为真正的级联删除（素材、Wiki、笔记、学习记录与向量索引一并清理），不再只是标记隐藏；删除后知识库页提供「创建内置知识库」入口，按当前随包内容重新生成，旧版软删除记录也会在重新创建时彻底清理。

## 0.1.2 — 2026-10-18

### 新增

- Docker 生产部署：新增前后端镜像、独立 Compose 编排与一键部署脚本，可在单机或内网自托管。
- 默认采用非常规端口，避开开发环境与常见默认值：Web `18473`、API `18474`、PostgreSQL `15432`、Qdrant `16333 / 16334`；仅 Web 端口对外监听。
- `deploy.sh` 自动生成 `.env.prod`、随机数据库密码与 Fernet 密钥，并完成镜像构建、服务启动与数据库迁移。
- 持久化卷 `kiwi-prod-pgdata`、`kiwi-prod-qdrantdata`、`kiwi-prod-data`：容器重建不影响业务数据、上传文件、Notebook 工作区与嵌入模型缓存。
- 部署文档 [DEPLOY.md](DEPLOY.md)：端口规划、备份恢复、升级、沙箱权限与常见故障排查。
- 嵌入模型支持 OpenAI 兼容的线上接口：可在应用内 **设置 → 向量模型** 切换本地 / 线上，填写接口地址、密钥与模型名，支持连接测试与维度回显；密钥加密存储，环境变量 `KIWI_EMBED_*` 作为兜底。远程向量使用独立 Qdrant collection，避免与本地模型混写。
- 产品门户页 `portal/`：三种编辑模式、可执行代码、Notebook 与学习闭环的交互式展示；学习闭环支持自动轮播与悬停 / 聚焦暂停，并补充 404 页面、`robots.txt`、`sitemap.xml` 与 1200 × 630 社交分享封面，适配 GitHub Pages，无需构建。
- 前端开发服务器将仓库根目录的 `portal/` 挂载到 `/portal/`：访问 `http://localhost:5173` 默认进入门户首页，应用仍可通过 `/kbs`、`/notes` 等路径直接访问。
- 编辑 / 学习双模式品牌标识：知识网络与掌握度雷达两套 LOGO，同步应用到页头、favicon 与文档截图。

### 变更

- 后端容器入口在启动 API 前自动执行 `alembic upgrade head`，升级无需手工迁移。
- nginx 对 `/api/` 关闭代理缓冲并将超时放宽到 600 秒，保证问答与编译进度流式输出不被截断。
- 为 Notebook 沙箱配置 `SYS_ADMIN` 与放宽的 seccomp / AppArmor 策略；沙箱内部仍丢弃全部 capabilities 并隔离命名空间。
- 前后端镜像默认使用国内依赖源：后端使用清华 PyPI / Debian 镜像并改为从 PyPI 安装固定版本 `uv`，前端使用 `registry.npmmirror.com`；apt、uv 与 npm 下载均启用 BuildKit 缓存，国内网络下重复构建显著加快。
- 嵌入模型下载默认使用 `https://hf-mirror.com`，首次摄入不再依赖 Hugging Face 官方网络。

### 修复

- 线上向量模型保存失败时不再显示 `[object Object]`：前端会把 FastAPI 校验错误转换为可读文案；超时、批大小与并发数在失焦时自动收敛到允许范围，并显示取值范围提示；高级参数区会说明批大小与并发数的含义，以及调高后更容易触发服务商单请求上限或 429 限流的风险。
- 前端镜像构建的 Node 堆上限从 4 GB 调整为 2 GB（实测峰值约 2.0–2.2 GB），并关闭压缩体积统计，降低低内存主机在 `vite build` 阶段触发 OOM、导致 SSH 连接中断的风险；可通过 `NODE_MAX_OLD_SPACE_MB` 调整。

## 0.1.0 — 2026-10-18

首个完整版本：从笔记工作区、Wiki 编译到学习闭环的全部核心流程可用。

### 笔记工作区

- 统一笔记模型：文档、数据表、导入、外链、画布与 Notebook 共用目录树、标签、模板与双向链接。
- 目录树支持分组、拖拽移动与排序、内联重命名、搜索与展开状态持久化。
- 富文本编辑器：标题、列表、任务列表、表格、代码块、引用、图片、附件、高亮、对齐与斜杠命令。
- 数据表支持表格、看板、画册、日历四种视图，以及字段管理与行内联编辑。
- 文件导入自动解析为可编辑文档，保留原始素材并显示导入进度与解析质量。
- 外链笔记由服务端抓取正文，抓取失败时降级为书签卡片。
- 画布支持绘制工程图与思维导图，箭头智能粘连、节点对齐辅助与主题切换。
- Notebook 在隔离沙箱中执行代码，结果以图形化方式呈现。
- 附件上传与 `/media` 静态访问，图片可直接粘贴或拖入正文。

### Wiki 编译

- 知识库内全部笔记与素材统一进入编译流水线，而非仅导入素材。
- Schema 驱动的概念抽取与页面组织，支持增量编译、引用来源与受影响页面追踪。
- 编译任务展示实时进度、阶段耗时与解析质量，失败项可定位重试。
- 支持整库重新编译；Wiki 页面提供目录、大纲、反向链接与来源逆向跳转。

### 知识星图

- 星图式浏览 Wiki 页面关系，节点大小反映被引次数。
- 支持按页面、笔记等节点类型筛选，悬浮高亮与关系层级控制。

### 学习闭环

- 学习者画像与按掌握度动态排程的学习计划。
- 渐进练习、间隔重复与错题本。
- 仿真考试支持分卷作答、知识点雷达与成绩报告。
- 掌握度回写到 Wiki 页面与学习图谱，薄弱点可直接定位到知识内容。

### 知识问答

- Wiki 与原文混合检索，回答附带可溯源引用，并可回写为新 Wiki 页面。
- 兼容任意 OpenAI 协议模型，API Key 使用 Fernet 加密存储。

### 内置演示

- 首次启动注入「Kiwi 上手指南 · 功能演示知识库」，覆盖全部笔记类型、Wiki 页面、学习计划与考试数据，可修改、删除或还原。
