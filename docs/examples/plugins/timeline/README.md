# 时间轴组件插件

竖向时间轴区块。每个时间点包含「时间 + 摘要 + 正文」，收起时只显示时间与摘要，
展开后可以在该时间点下编写笔记内容；支持关键时间点标记、自由增删与调整节点顺序。

## 安装

1. 在仓库根目录执行 `npm run package`，生成 `dist/timeline-1.3.0.zip`。
2. 打开 Kiwi「设置 → 插件与区块 → 导入插件」，选择 zip（同 key 覆盖安装会保留启用状态）。
3. 在编辑器输入 `/时间轴`，或从「+ → 插件区块」插入。

## 行为

- 时间点保存在 props `points` 数组中，随笔记一起持久化，刷新或切换笔记后不丢失。
- 点击时间点右侧的 `▸ / ▾` 展开或收起；收起时仅显示摘要，展开后显示正文编辑区。
- 正文使用宿主提供的富文本编辑器（`host.components.NoteEditor`），与文本笔记一样
  支持标题、加粗 / 斜体 / 下划线 / 删除线、引用、代码、有序 / 无序列表，以及
  **待办勾选框**；勾选后的条目会划掉并弱化。
- 正文以 Markdown 保存在每个时间点的 `content` 字段中；旧版本 Kiwi 没有
  `host.components` 时自动回退为纯文本 textarea，已有内容不丢失。
- 点击 `☆ / ★` 把时间点设为关键节点，圆点与时间文字用琥珀色区分。
- 「+ 添加时间点」追加一个以当前时间命名的节点；每个节点右侧的 `×` 可删除。
- 每个节点右侧的 `↑ / ↓` 调整先后顺序：`points` 数组顺序就是展示顺序，
  首 / 末节点的对应方向按钮自动禁用；调整后立即持久化，刷新不丢失。
- 时间文本为自由格式（如 `09:00`、`10-29`、`第 1 天`），不做自动排序，
  节点顺序完全由手动调整决定。
- 阅读视图同样可以展开 / 收起，正文按 Markdown 渲染（待办勾选框不可修改），
  但不显示编辑、删除与排序按钮。
- 颜色使用 `--kiwi-*` 主题变量，跟随系统主题色；窄编辑器下自动压缩时间列。

## 文件

- `plugin.json`：manifest
- `index.js`：入口 ESM，导出 `setup(host)`
- `style.css`：区块样式
