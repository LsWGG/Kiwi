# Kiwi 功能速查表

## 1. 输入

- 新建文档：左侧目录「+」→ 文档
- 导入文件：支持 Markdown、PDF、DOCX、TXT、HTML
- 外链抓取：粘贴 URL，自动提取正文
- 快速记录：收件箱适合先记后整理

## 2. 整理

- 目录树：拖拽排序、移动分组
- 标签：跨目录聚合，可在图谱中作为筛选依据
- 模板：预填标题、正文、标签
- 数据表：表格 / 看板 / 画册 / 日历
- 画布：工程图、流程图、思维导图

## 3. 理解

- Wiki 编译：资料 → 概念页 + 引用关系
- 双向链接：@ 提及笔记与 Wiki
- 反向链接：查看谁引用了当前页面
- 知识图谱：精要 / 完整、聚焦、掌握度
- 问答：基于检索结果回答并标注来源

## 4. 掌握

- 学习画像：目标、基础、每日时长
- 渐进训练：一题一练，即时反馈
- 复习队列：间隔重复，到期提醒
- 仿真考试：整卷计时、自动评分
- 学习批注：个人理解，不写回 Wiki

## 5. 推荐节奏

| 周期 | 动作 |
|---|---|
| 每天 | 清空收件箱；完成到期复习 |
| 每周 | 导入一批资料；编译 Wiki；整理标签 |
| 每两周 | 一次仿真考试；复盘薄弱点 |
| 每月 | 清理孤立页面；更新模板与数据表 |
