# Kiwi 功能速查表

## 1. 输入

- 新建文档：左侧目录「+」→ 文档
- 导入文件：支持 Markdown、PDF、DOCX、TXT、HTML
- 外链抓取：粘贴 URL，自动提取正文
- 快速记录：收件箱适合先记后整理

## 2. 整理

- 目录树：拖拽排序、移动分组
- 标签：跨目录聚合，可在图谱中作为筛选依据
- 模板：预填标题、正文、标签
- 数据表：表格 / 看板 / 画册 / 日历
- 画布：工程图、流程图、思维导图

## 3. 理解

- Wiki 编译：资料 → 概念页 + 引用关系
- 双向链接：@ 提及笔记与 Wiki
- 反向链接：查看谁引用了当前页面
- 知识图谱：精要 / 完整、聚焦、掌握度
- 问答：基于检索结果回答并标注来源

## 4. 掌握

- 学习画像：目标、基础、每日时长
- 渐进训练：一题一练，即时反馈
- 复习队列：间隔重复，到期提醒
- 仿真考试：整卷计时、自动评分
- 学习批注：个人理解，不写回 Wiki
- 学习周报：答题量、正确率、薄弱点与留存曲线
- 提醒：每日复习 / 待办与每周报告，可推送浏览器通知

## 5. 进阶能力

- 语音转写：实时录音 + 本地字幕，或上传音频；停止后生成带时间戳的会议笔记
- 飞书妙记：设置页扫码授权后，音频上传飞书生成妙记，失败自动回退本地
- 贴一贴：双击目录中的笔记，以浮窗置顶展示；可同时打开多篇，自由拖动和缩放
- 组件插件：内置组件可导出参考包；第三方 zip 插件支持预览、导入、启停与导出
- 只读分享：免登录访问，支持 1 小时 / 1 天 / 7 天 / 30 天有效期、访问密码与撤销

## 6. 表格、导入与交付

- 表格笔记：Excel 式多工作表，支持公式、合并单元格、冻结窗格、筛选、排序与样式
- 表格导入：CSV / XLSX / XLS，可保留多工作表、公式与合并单元格
- OCR：PDF 文本层缺失或图片资料可勾选「强制 OCR」
- 导出：文档导出 Markdown / PDF / Word；表格与数据表导出 Excel / CSV；Notebook 导出 ipynb / py；画布导出 PNG / PDF / SVG

## 7. 问答、待办与 Anki

- 问答：向量 + BM25 混合检索 → RRF 融合 → 可选重排；回答标注来源并可跳转
- 会话：按库 / 多库 / 全局检索，支持按笔记类型、标签与更新时间筛选
- 待办汇总：自动汇总笔记任务与数据表状态行到收件箱，勾选后写回来源
- 编译范围：除自动待办汇总、只读导入材料与数据表行笔记外，全部笔记都可编译
- Anki：题库可导出 .apkg（按题型 / 知识点拆子牌组），也可导入 .apkg / .colpkg 并自动去重

## 8. 推荐节奏

| 周期 | 动作 |
|---|---|
| 每天 | 清空收件箱；完成到期复习 |
| 每周 | 导入一批资料；编译 Wiki；查看学习周报 |
| 每两周 | 一次仿真考试；复盘薄弱点 |
| 每月 | 清理孤立页面；更新模板与数据表；导出备份 |
